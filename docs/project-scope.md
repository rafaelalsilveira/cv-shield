
# CV Shield — Project Scope

## 1. Project Objective

CV Shield is a project designed to analyze PDF resumes and identify potentially hidden content and suspicious instructions that may target AI-powered recruitment systems.

The system will support human review and will not make hiring decisions.

## 2. MVP Scope

The first version of CV Shield will focus on:

- Reading text from PDF resumes.
- Identifying potentially hidden or invisible text.
- Detecting suspicious instructions embedded in resumes.
- Generating a structured analysis report.
- Testing with fictional or anonymized resumes.

## 3. Out of Scope for the MVP

The following features will not be part of the initial version:

- Automatic hiring or rejection decisions.
- Fully autonomous recruitment.
- Advanced AI analysis.
- Complete n8n integration.
- Web interface.

These features may be considered in future versions.

## 4. Planned Technologies

- Python: PDF analysis and detection logic.
- Git: Version control.
- GitHub: Project repository and portfolio.
- n8n: Workflow automation in a future integration.

## 5. Ethical Principles

CV Shield should:

- Support human review.
- Avoid making hiring decisions.
- Report evidence instead of assuming malicious intent.
- Protect personal information in test documents.
- Use fictional or anonymized resumes whenever possible.

## 6. Development Approach

The project will be developed incrementally:

1. Define the project scope.
2. Build a basic PDF text extraction process.
3. Investigate hidden or suspicious content.
4. Create tests with sample documents.
5. Generate structured reports.
6. Explore n8n integration.
